# Wireframe — Khoá FUNDAMENTAL

Wireframe bố cục cho trang khoá học FUNDAMENTAL của Monster Lab.

Xem tại: https://vuminhdesigner-spec.github.io/wireframe/

## Nội dung

Một file `index.html` duy nhất, không phụ thuộc thư viện nào. Mười hai khối nội dung theo
đúng thứ tự của trang thật, mỗi khối kèm số thứ tự và nhiệm vụ ở cột trái.

Hoàn toàn xám: ảnh là khung gạch chéo, đoạn văn là thanh xám, chữ thật chỉ giữ ở tiêu đề
và nhãn. Mục đích là chốt mạch nội dung trước khi bàn tới màu sắc và hình ảnh.

## Bật GitHub Pages

Settings → Pages → Source: `main`, thư mục `/`.

## Nguồn

Bản gốc nằm trong repo `monsterlab`, đường dẫn `landing-fundamental/wireframe/index.html`.
Sửa ở đó trước, rồi copy sang đây.
